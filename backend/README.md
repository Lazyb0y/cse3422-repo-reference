# Backend

Put the backend app here (Spring Boot, Express/NestJS, Django/FastAPI, Laravel, ASP.NET Core, …), created with its official tool so it has its own build file (`pom.xml`, `build.gradle`, `package.json`, `requirements.txt` or `pyproject.toml`, `composer.json`, or a `.sln`). CI finds it automatically and builds and tests it.

Database migrations live with the backend code (Flyway, Prisma, Django or Laravel migrations, EF Core, …).

Using two repositories, or one app at the root? Delete this folder.
